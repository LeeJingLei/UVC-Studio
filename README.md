# UVC Studio 使用指南

UVC Studio 用于预览和操作 Windows 电脑连接的 UVC 摄像头。你可以选择摄像头的视频模式、查看实时画面、调节摄像头参数、录制视频和拍摄照片。

## 安装与启动

1. 双击下载的 UVC Studio 安装程序（`.exe`），按提示完成安装。
2. 从 Windows 开始菜单启动 **UVC Studio**。
3. 将摄像头连接到电脑。如果刚刚插入摄像头，点击顶部的“扫描设备”刷新设备列表。

## 开始预览

1. 在顶部设备列表中选择要使用的摄像头。
2. 在旁边的视频格式列表中选择分辨率、帧率和像素格式。列表显示该摄像头可用的模式。
3. 点击“开启相机”开始预览。再次点击该按钮可关闭相机。

预览画面下方会显示当前状态和实际接收到的视频帧率。双击预览画面可进入或退出全屏；也可以打开“更多”菜单，选择“全屏”。全屏时按 `Esc` 返回窗口。

## 调整摄像头

打开“更多”菜单，选择“相机控制”显示控制面板。开启预览后，程序会读取摄像头支持的控制项；也可以点击面板中的“读取当前”重新读取。

拖动滑块或修改数值框即可调整参数。支持自动控制的项目会显示“自动”选项：勾选时由摄像头自动调节，取消勾选后可手动设置。点击“恢复默认”可将可用的标准 UVC 控制项恢复为设备默认值。

不同摄像头和驱动提供的控制项可能不同。如果面板提示设备没有公开标准 UVC 控制，预览、录制和拍照仍可使用。

## 录制视频与拍照

开始预览并等待画面正常显示后，打开“更多”菜单：

- 选择“录制”开始录制，再选择“停止录制”结束并保存视频。视频以 MP4 格式保存到 Windows“视频\UVC Studio”文件夹，文件名包含拍摄时间。
- 选择“拍照”保存当前画面。照片以 JPEG 格式保存到 Windows“图片\UVC Studio”文件夹，文件名包含拍摄时间。

如果“录制”或“拍照”不可用，请先开启摄像头并等待预览画面出现。

## 控制日志与详细信息

在“更多”菜单中选择“控制日志”可查看摄像头控制记录。日志面板提供“清空”和“导出 CSV”功能，导出的文件可用表格软件打开。选择“详细信息”可查看当前视频流的运行信息。

## 常见情况

- **列表中没有摄像头：** 检查摄像头是否连接，然后点击“扫描设备”。
- **无法开启摄像头：** 关闭可能正在使用该摄像头的其他应用，再尝试开启。
- **没有相机控制项：** 摄像头或驱动可能未提供标准 UVC 控制；这不影响预览、录制和拍照。
